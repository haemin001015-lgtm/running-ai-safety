# AI 생활안전망 · 청년러닝방범대

야간 순찰 중 발견한 밤길 위험을 기록하고, 민원 문안까지 만들어 주는 앱입니다.
중앙청년LAB × 성균관대학교 AXIS Lab, 2026 자원봉사 아이디어톤 실행 과제.

**앱 주소** → https://haemin001015-lgtm.github.io/running-ai-safety/

## 대원용 사용법

1. 위 주소를 폰에서 엽니다.
2. 처음 한 번 이름과 조를 입력합니다.
3. **홈 화면에 추가**해 두면 앱처럼 열리고, 인터넷이 없어도 켜집니다.
   - 아이폰: 공유 → 홈 화면에 추가
   - 안드로이드: 메뉴 → 앱 설치(홈 화면에 추가)
4. 순찰 시작 → 위험을 발견하면 **제보** 탭에서 사진·위치·메모를 남깁니다.
5. 인터넷이 안 되는 곳에서도 등록됩니다. 연결되면 자동으로 팀 저장소에 전송됩니다.

기록한 사진과 위치는 이 기기에 저장되고, 팀 저장소를 연결한 경우 크루장에게 함께 전달됩니다.
사진에 얼굴이나 차량번호가 담기지 않도록 주의해 주세요.

## 크루장용 · 팀 저장소 만들기 (약 10분, 한 번만)

대원들의 제보를 구글 시트 한 곳에 모으는 설정입니다. 하지 않아도 앱은 각 기기에서 그대로 동작합니다.

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (이름 예: `러닝방범대 제보`)
2. 시트 상단 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣습니다.
4. 맨 위 `var TOKEN = 'CHANGE-ME-팀키';` 의 값을 팀만 아는 문자열로 바꾸고 저장합니다.
   - 사진도 함께 모으려면 드라이브 폴더를 만들고 그 폴더 ID를 `PHOTO_FOLDER_ID`에 넣습니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포를 누르고 권한을 허용한 뒤 나오는 **웹 앱 URL**을 복사합니다.
6. 앱의 **설정(⚙️)** 화면에 URL과 팀 키를 붙여넣고 **연결 테스트** → 저장.
7. 대원들에게 같은 URL과 팀 키를 알려주면, 모든 제보가 시트에 모입니다.

### 대원에게 배포할 때 (설정 링크)

대원들이 주소·키를 직접 입력하지 않아도 되도록, 설정을 담은 링크를 만들 수 있습니다.

```
앱주소/?setup=<설정값>
```

`설정값`은 `{"u":"웹앱URL","t":"팀키","c":{"nm":"코스이름","why":"설명","dist":"1.1km","time":"15분","spots":"24"}}`
를 base64(URL 안전)로 인코딩한 값입니다. 링크를 한 번 열면 저장소·코스가 자동 설정되고,
팀 키는 주소창에서 즉시 지워집니다. **이 링크에는 팀 키가 들어 있으니 대원에게만 보내세요.**

코드를 수정하면 **배포 → 배포 관리 → 편집 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 기능

| 화면 | 하는 일 |
| --- | --- |
| 순찰 | 코스 정보 확인, 순찰 시작/종료, 시간 자동 기록(앱을 닫아도 유지) |
| 제보 | 사진(자동 축소) · 위치(정확도 표시) · 메모, 위험 유형 13종 자동 분류와 직접 선택 |
| 위험지도 | 35m 이내 제보 묶기, 사고다발지역 거리 결합, 위험 점수 순위 |
| 내 활동 | 누적 봉사시간, 활동 기록, CSV 내보내기 |

민원 문안은 위치·유형·반복 관측 이력·인근 사고이력·데이터 출처를 담아 자동으로 만들어지며,
복사 · 공유 · 안전신문고 열기로 이어집니다.

위험 점수 = 반복 제보 × 2 + 유형별 가중치 + 사고다발지역 100m 이내 5점
