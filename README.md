# 러닝으로 만드는 AI 생활안전망

청년러닝방범대 앱 **프로토타입 웹 데모**입니다. 별도 빌드나 서버 없이 `index.html` 하나로 동작합니다.

## 데모

GitHub Pages를 켜면 아래 주소에서 바로 열립니다.

```
https://<username>.github.io/running-ai-safety-net/
```

로컬에서 볼 때는 `index.html`을 브라우저로 열거나:

```bash
python3 -m http.server 8000
```

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 순찰 | 오늘의 코스(거리·예상 시간·점검 지점), 순찰 시작/진행, 이번 주 팀 실적 |
| 제보 | 사진 → 위치 자동 저장 → 메모 입력, AI 자동 유형 분류 후 등록 |
| 위험지도 | 안양 야간 위험지도 — 사고다발지역·미조치·개선 완료·순찰 코스, 위험 순위 |
| 내 활동 | 누적 봉사시간(1365 자원봉사포털 실적 연계), 순찰·제보·개선 확인 기록 |

## 기술 메모

- 의존성 없는 순수 HTML/CSS/JS 단일 파일
- **Paperlogy** 폰트를 woff2 base64로 파일 안에 내장 — 네트워크 요청이나 폰트 CDN 없이 어디서든 동일하게 렌더링됩니다
- 제보·순찰 기록은 `localStorage`에 저장되어 새로고침 후에도 유지됩니다
- 지도·통계 수치는 시연용 시드 데이터입니다

## 라이선스

폰트 라이선스(Paperlogy)는 원 배포처 조건을 따릅니다.
