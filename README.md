# AI 생활안전망 · 청년러닝방범대

야간 순찰 중 발견한 밤길 위험을 기록하고, 민원 문안까지 만들어 주는 앱입니다.
중앙청년LAB × 성균관대학교 AXIS Lab, 2026 자원봉사 아이디어톤 실행 과제.

**앱 주소** → https://cyouthlab.co.kr
(기존 주소 https://haemin001015-lgtm.github.io/running-ai-safety/ 도 그대로 연결됩니다)

## 대원용 사용법

1. 위 주소(**cyouthlab.co.kr**)를 폰에서 엽니다.
2. 처음 한 번 이름과 조를 입력합니다.
3. **홈 화면에 추가**해 두면 앱처럼 열리고, 인터넷이 없어도 켜집니다.
   - 아이폰: 공유 → 홈 화면에 추가
   - 안드로이드: 메뉴 → 앱 설치(홈 화면에 추가)
4. 순찰 시작 → 위험을 발견하면 **제보** 탭에서 사진·위치·메모를 남깁니다.
5. 인터넷이 안 되는 곳에서도 등록됩니다. 연결되면 자동으로 팀 저장소에 전송됩니다.

기록한 사진과 위치는 이 기기에 저장되고, 팀 저장소를 연결한 경우 크루장에게 함께 전달됩니다.
사진에 얼굴이나 차량번호가 담기지 않도록 주의해 주세요.

## 크루장용 · 팀 저장소

대원들의 제보는 구글 시트 한 곳에 모입니다. **대원은 아무 설정도 하지 않습니다** — 주소만 열면 됩니다.

저장소를 새로 만들거나 옮길 때만 아래를 따릅니다.

1. 구글 스프레드시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱** (실행: **나**, 액세스: **모든 사용자**) → 웹 앱 URL 복사
4. `assets/app.js` 맨 위 `DEFAULT_URL` 값을 그 URL로 바꿔 배포합니다.

별도의 팀 키는 쓰지 않습니다. 외부에서 장난 기록이 들어오면 Apps Script를 **새 주소로 재배포**하고
`DEFAULT_URL`만 교체하면 즉시 차단됩니다. 사진까지 모으려면 드라이브 폴더를 만들고
`Code.gs`의 `PHOTO_FOLDER_ID`에 폴더 ID를 넣으세요.

## 기능

| 화면 | 하는 일 |
| --- | --- |
| 순찰 | 코스 정보 확인, 순찰 시작/종료, 시간 자동 기록(앱을 닫아도 유지) |
| 제보 | 사진(자동 축소) · 위치(정확도 표시) · 메모, 위험 유형 13종 자동 분류와 직접 선택 |
| 위험지도 | 35m 이내 제보 묶기, 사고다발지역 거리 결합, 위험 점수 순위 |
| 내 활동 | 누적 봉사시간, 활동 기록, CSV 내보내기 |

민원 문안은 위치·유형·반복 관측 이력·인근 사고이력·데이터 출처를 담아 자동으로 만들어지며,
복사 · 공유 · 안전신문고 열기로 이어집니다.

위험 점수 = 반복 제보 × 2 + 유형별 가중치 + 사고다발지역 100m 이내 5점
